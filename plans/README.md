# plans/

Things written to build: plans, designs, PRDs. Dated filenames, `YYYY-MM-DD-<slug>.md`.

Lifecycle: mutable while in flight, archived on ship. The shipping session moves its plan to `archives/plans/` in the same close-out (`governance/repo-contract.md`, Archive lifecycle); weekly hygiene is the backstop.

`workstate/` holds live per-task state files (see its README). Plan-first rule: anything non-trivial gets its plan reviewed here before a single file is built (`governance/building.md`).
