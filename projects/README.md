# projects/

One folder per workstream: your company's projects, side projects, explorations. This README's table is the index; registering a project here is part of creating it.

Working files (PRDs, drafts, thinking) live in the project folder; knowledge with provenance lives in the wiki; deliverables link wiki slugs. Code never lives here: each project folder lists its external repos (path, remote, one-line role). A repo that touches this hub is a satellite and also gets a row in `operations.md` `## Satellites` (`governance/satellite-repos.md`).

Lifecycle: row here → own file → own folder → graduates (spins out or winds down; its folder moves to `archives/`).

Root folders stay venture-agnostic (this hub should outlive any single company); anything venture-specific nests inside that venture's project folder. Confidentiality categories, including any folder-level ones, are declared in `governance/confidentiality.md`.
