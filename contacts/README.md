# contacts/

The local contact store: one YAML file per person, maintained by script once the wiki loop starts meeting people in your transcripts. Identity resolution for roster mapping; wiki entity pages are the curated layer on top.

`_not_names.yml` is the anti-registry: speech-to-text artifacts that look like proper nouns and are not. A name listed there never resolves to a person. It fills up fast once real transcripts flow; keep it.
