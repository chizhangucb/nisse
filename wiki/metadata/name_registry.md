# Name Registry

Canonical spellings for proper nouns that transcription mangles. One row per resolved name: how it was misheard, who or what it actually is, and the source that settled it. Checked first in proper-noun resolution (`wiki/rules.md`); the anti-registry (things that look like names and are not) is `contacts/_not_names.yml`.
