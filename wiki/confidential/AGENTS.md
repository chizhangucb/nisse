# Confidential pages

Same schema as the rest of the wiki (`wiki/AGENTS.md`, one level up) plus one hard rule: nothing in this folder ever feeds external output.

- Routing here is fail-closed: could go either way means it lands here. Rule 7 in the schema governs.
- These pages may link out. Nothing links in with content: an open page never quotes or summarizes what lives here.
- Never paste, draft, or summarize this material into anything leaving the machine. `docs/confidentiality.md` governs, and a `CONFIDENTIAL` marker file carries the same weight for any folder holding it.
- The folder exists from day one even when empty. That is what makes the fail-closed rule enforceable instead of aspirational.
